# NovaStream

**NovaStream** is an independently branded, highly customizable multimedia center and video player for Android and Android TV, based on the modified open-source CloudStream project.

## Key Features

- **Independent Identity**: Branded application ID (`com.rindou.novastream`) allowing clean side-by-side installation with standard CloudStream.
- **On-Demand Category Loading**: Fast homepage startup loading the first category immediately, with a dedicated on-demand "Load More Categories" trigger.
- **Interactive Multi-Facet Search & Filters**: Support for facet-based queries, sorting tokens, and rich media filtering.
- **Batch Download Verification**: Pre-flight HTTP stream probing and AB Download Manager batch chunking.
- **Zero Ads & Privacy-Focused**: No advertising, tracking, or invasive telemetry.
- **Full Form-Factor Support**: Optimized for both touch phones/tablets and Android TV Leanback navigation.
